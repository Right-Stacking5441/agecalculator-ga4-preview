# agecalculator.com GA4 consent preview

This is a noindex preview of the cookie-consent and Google Analytics 4 work for agecalculator.com. It is not the live site.

Live site: https://agecalculator.com (from Right-Stacking5441/agecalculator, branch main). A push to that main branch would go live; this repository exists so the work can be reviewed without touching it.

Pages are served from this repository's main branch root, with a robots.txt `Disallow: /` and a noindex, nofollow meta tag on every HTML page. There is no CNAME.
